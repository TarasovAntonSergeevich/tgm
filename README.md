# Telegram Bot Survey

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Отредактируйте `config.py`:
- `BOT_TOKEN` - токен бота от @BotFather
- `ADMIN_ID` - ваш Telegram ID (узнать: @userinfobot)

## Запуск

```bash
python bot.py
```

## Функционал

1. Пользователь стартует бота -> отвечает на вопрос
2. Выбирает категорию (2 варианта) -> видит 4 товара
3. Вводит имя -> город
4. Данные сохраняются в SQLite

## Админ-панель

Команда `/admin` - получить список всех пользователей бота (доступ только у ADMIN_ID)
